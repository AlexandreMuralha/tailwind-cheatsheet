# Tailwind CSS Cheatsheet

[🌐 Live Version](https://tailwind-cheatsheet-topaz.vercel.app/)
[GitHub Repository](https://github.com/alexmuralha/tailwind-cheatsheet)

A personal Tailwind CSS cheatsheet built with Next.js and TypeScript. This project serves as a quicker reference than the [complete official documentation](https://tailwindcss.com/docs), focusing on the utilities I frequently use.

## 🛠️ Built With

- [Next.js](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Shadcn UI](https://ui.shadcn.com/)
